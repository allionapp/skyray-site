Support

Email ehusa86@gmail.com. Include the app version (Settings → Core) and, if a connection fails, the tunnel log (Settings → Tunnel log → Copy log). The log never contains your credentials.

Common questions

The link I pasted is not recognised

Copy the whole line from your provider, from vless:// (or vmess, trojan, ss, ssh, tuic) to the end. Links usually end with a name after #. If it keeps failing, ask your provider for a QR code – it cannot be cut off.

Connected, but nothing loads

Test the server (Servers → ⋯ → Test all latencies). If it times out, the server is down or blocked; pick another. In Settings you can also enable “Fragment TLS handshake”, which helps on some networks.

Iranian sites are slow or blocked while connected

Settings → Routing → “Bypass Iran and LAN” sends Iranian domains and IPs directly.

The VPN turns off when the phone sleeps

Settings → Connection → keep “Stay connected while the screen is locked” on, and optionally enable “Connect on demand”.

How do I remove everything?

Servers → ⋯ → Delete all servers, or delete the app. Nothing is stored outside your device.
